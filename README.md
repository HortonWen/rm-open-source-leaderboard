# RoboMaster 战队开源排行榜

一个完全离线的静态网站：汇总 RoboMaster 各战队在 GitHub、Gitee 与 RoboMaster 论坛开源专栏的贡献，按自建评分模型生成开源贡献排行榜，支持“按大学 / 按战队”双视图、搜索、地区/来源筛选、六维开源雷达图、论坛开源帖列表和实时 GitHub 检索。

## 视图说明

- **按大学**（默认）：同一所大学的多支战队合并为一个大学条目（如浙江大学 = Hello World + Meta，香港科技大学 = 本部 ENTERPRIZE + 广州 PNX）。点击大学可查看该大学全部战队的明细，每个仓库与论坛帖都标注所属战队。
- **按战队**：每支战队独立排名（原视图）。

## 文件

- `index.html` —— 站点页面（打开即用，无需服务器）
- `data.js` —— 数据快照（2026-08-05 抓取自 GitHub，非官方）

## 评分模型

综合得分 = 影响力(Star) 35% + 传播度(Fork) 15% + 输出量(仓库数) 20% + 活跃度(最近更新) 10% + 多元性(语言×赛季) 10% + 社区输出(论坛开源帖) 10%。
各维度按对数刻度折算为绝对 0-100 分（Star 满刻度 600、Fork 160、仓库数 30、语言×赛季 12、论坛帖 8；活跃度按最近更新距今月数指数衰减）。
综合得分 = 40 + 0.6 × 六维加权和：参与开源即有 40 分基础分，顶尖队伍约 95 分以上，分数为绝对分而非全量排名归一化。

## 数据口径

- 快照抓取：GitHub 搜索 API + 战队组织页面；Gitee API（战队账号 + 已知仓库）；RM 论坛算法/电控/机械/AWARD 开源专栏。
- 同一战队的多个账号/平台已合并统计（如东北大学 TDT、南航长空御风、浙大 Hello World、西电 IRobot、湖大跃鹿 GitHub/Gitee 镜像等）。
- 官方账号（DJI、RoboMaster OSS）、商业公司（天之博特、aubo 等）、社区项目（rm-controls 等）不计入战队榜，个人开发者单独列入“个人开源贡献榜”（目前仅统计 GitHub）。
- 论坛帖统计口径：四个开源专栏的 2022-2025 优质帖（含 AWARD 分享）；汇总帖中的 2015-2020 历史索引在腾讯文档中，未逐条展开。
- 未收录：无公开仓库或论坛帖记录的战队，见页面“收录情况说明”。

## 实时刷新

页面底部“实时检索 GitHub 开源内容”直接调用 GitHub 搜索 API（浏览器未登录额度为 10 次/分钟，超限稍后再试）。

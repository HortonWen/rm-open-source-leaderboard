# 机甲大师（RoboMaster）开源资源目录

汇总 RoboMaster 各战队、个人开发者在 GitHub、Gitee 与 RoboMaster 论坛开源专栏的开源代码、图纸与项目，并收录 DJI 官方及第三方公司的文档与 SDK。本站为**分类资源目录**，已取消排名机制，不再对战队做比较、打分或排序。

## 分类

- 官方资源（DJI / RoboMaster）
- 第三方公司（天之博特等）
- 社区框架与工具（视觉 / 电控 / 仿真 / SDK）
- 机械 / 图纸 / 结构
- 战队开源（按学校）
- 个人开源贡献
- 论坛开源帖

## 文件

- `index.html` —— 目录站点（打开即用，无需服务器）
- `data.js` —— 数据快照（2026-09-18，GitHub + Gitee + RM 论坛，非官方）
- `open-source-solutions.md` —— 同一份数据的 Markdown 版本

## 数据口径

- 收录：战队/个人公开仓库、机械图纸、官方 SDK、第三方公司文档、论坛开源帖。
- 官方账号（DJI、RoboMaster）、商业公司、社区项目与战队/个人分列展示，不再混排打分。
- 无公开仓库或论坛帖记录的战队见页面末尾清单。

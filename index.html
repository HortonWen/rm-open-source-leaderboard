开源贡献评分体系

综合得分 = 影响力 35% + 传播度 15% + 输出量 20% + 活跃度 10% + 多元性 10% + 社区输出 10%（各维度按对数刻度折算为绝对 0-100 分；综合分 = 40 + 0.6×加权和，参与开源即有 40 分基础分）。

影响力 35%

GitHub + Gitee 仓库总 Star 数（对数缩放）：被多少人收藏 / 引用。

传播度 15%

仓库总 Fork 数：被多少团队二次开发，代表实用性与社区扩散。

输出量 20%

公开仓库数量（GitHub + Gitee）：机械 / 电控 / 算法 / 文档各方向持续产出。

活跃度 10%

最近更新距今时长：是否仍在维护、是否跟得上新赛季。

多元性 10%

语言种类 + 覆盖赛季数：技术栈广度与参赛年限沉淀。

社区输出 10%

RoboMaster 论坛开源专栏发帖数（算法 / 电控 / 机械 / AWARD 分享）。
